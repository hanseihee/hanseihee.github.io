GA4 Daily Report 개인정보처리방침

시행일: 2026년 9월 20일

개요

GA4 Daily Report는 개발자 본인이 권한을 가진 Google Analytics 4 속성의 집계 지표를 매일 읽어 사내 Slack 채널로 요약 보고서를 보내는 개인용 자동화 도구입니다. 일반 사용자를 대상으로 하지 않습니다.

접근하는 데이터

  • Google Analytics 읽기 전용 권한(analytics.readonly)만 요청합니다.
  • 활성 사용자 수, 세션 수, 조회수 등 집계된 통계만 조회하며, 개별 사용자를 식별할 수 있는 정보는 조회하지 않습니다.
  • Google Analytics 데이터를 수정·삭제하지 않습니다.

보관 및 공유

조회한 집계 수치는 지정된 Slack 채널로 전송되는 메시지에만 사용되며 별도로 저장하거나 제3자에게 판매·제공하지 않습니다. 인증 토큰은 암호화된 저장소(GitHub Actions Secrets)에만 보관됩니다.

권한 철회

Google 계정 권한 페이지에서 언제든지 접근 권한을 철회할 수 있습니다.

Privacy Policy (English)
GA4 Daily Report is a personal automation tool that reads aggregated metrics from Google Analytics 4 properties the developer already has access to, and posts a daily summary to an internal Slack channel. It requests read-only access (analytics.readonly), reads only aggregated statistics, never modifies Analytics data, and does not store, sell, or share the data with third parties. Tokens are kept only in encrypted CI secrets. You can revoke access at any time at myaccount.google.com/permissions.
